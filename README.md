# Poker Evaluator & Smart Decision Helper

Aplikasi berbasis web untuk membantu menganalisis kombinasi kartu poker (Texas Hold'em), persentase Win Equity, saran strategi betting, serta kalkulasi ancaman kartu lawan (The Nuts).

## Fitur Utama
- **Evaluasi Hand:** Deteksi otomatis kombinasi kartu tangan dan komunitas.
- **Saran Betting:** Rekomendasi tindakan (Fold/Check/Bet/Raise) beserta kalkulasi ukuran chip (Blind 300/600).
- **Analisis Threats:** Menganalisis potensi Flush (berdasarkan simbol) dan Quads/Full House jika ada pair di meja.
- **UI Responsif:** Nyaman digunakan melalui layar HP maupun Desktop.

## Teknologi
- HTML5, CSS3, JavaScript (ES6 Modules)
- Hosted via GitHub Pages
